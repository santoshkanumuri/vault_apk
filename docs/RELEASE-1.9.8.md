# Nuvori 1.9.8

Version code: 34. Package: `com.application.private_vault`.

Private Vault is now Nuvori, with the tagline "Yours, by design." The Android package, signing identity, encrypted database, and backup format remain unchanged, so this release installs over the previous version without moving vault data.

The new light and dark themes use a green palette based on the Nuvori mark. The transparent in-app mark appears only during onboarding and unlock, while ordinary vault pages retain simple text headings. The launcher uses the dark-background logo.

Home now uses category icons in its compact summary. Folder cards fit more information into less space, and the pull-up edit handle uses less vertical space. The NFC card-reading action remains a compact themed icon beside the card label.

Password import retains normalized column detection, manual heading mapping, repeated-row consolidation, per-account conflict choices, bulk Keep saved and Use imported actions, ambiguous-match protection, and atomic stale-preview checks. The review screen now filters accounts by All, New, Already saved, or Needs decision.

The repository README includes seven synthetic 1080 x 1920 product screenshots covering onboarding, Home, passwords, cards, authenticator codes, notes, and settings entry points. No real vault data appears in these images.

Nuvori still works offline and has no Internet permission. The vault and encrypted backup formats are unchanged.
